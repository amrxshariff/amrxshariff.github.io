## Selected work

### Uncertainty quantification in AI-assisted coronary artery disease diagnosis
*Final-year dissertation · CADICA dataset*

Trained two models on the same diagnostic problem from different data: a CNN with Monte Carlo dropout over angiographic image patches, and a random forest classifier over structured clinical metadata. Rather than comparing headline accuracy, I used Shannon entropy to compare how uncertain each model was, case by case.

Raw predictive performance was modest for both. That result is the reason the project takes the shape it does — a model that is often wrong is only dangerous if it is wrong *confidently*. The contribution is a tiered confidence routing framework that accepts low-entropy predictions, flags the ambiguous middle band, and escalates high-entropy cases to a clinician, converting an unreliable classifier into a triage aid that fails visibly rather than silently.

`Python` `scikit-learn` `MC dropout` `Shannon entropy` `tensorflow`

### Modelling sleep health outcomes across correlated populations
*Statistics for Large Data · R Markdown*

Generalised linear models and logistic regression for the outcome structure, mixed-effects models via `lme4` where observations were grouped rather than independent, and both hierarchical and k-means clustering tested against a change of distance metric to check the clusters were real rather than an artefact of the algorithm.

`R` `lme4` `tidyverse` `R Markdown` `ggplot` `lmer``glm`
