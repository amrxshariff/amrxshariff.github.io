Uncertainty quantification in AI-assisted coronary artery disease diagnosis

Final-year dissertation · CADICA dataset

Two models trained on the same diagnostic problem from different data: a convolutional neural network with Monte Carlo dropout over angiographic image patches, and a random forest classifier over structured clinical metadata. Rather than comparing headline accuracy, I used Shannon entropy to compare how uncertain each model was, case by case.

Raw predictive performance was modest for both — which is precisely why the project takes the shape it does. A model that is often wrong is only dangerous if it is wrong confidently. The contribution is a tiered confidence routing framework that accepts low-entropy predictions, flags the ambiguous middle band, and escalates high-entropy cases to a clinician, turning an unreliable classifier into a triage aid that fails visibly instead of silently.
